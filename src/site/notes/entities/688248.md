## 🔥 南网科技 × 虚拟电厂：算电协同国家标杆

> 南网科技不是聚合商，而是 **VPP + 构网型储能 + 电力电子"三合一"技术底座提供商**。粤能投平台是南方区域的算电协同核心载体。

### 粤能投 VPP 平台

| 维度 | 说明 |
|------|------|
| 定位 | 🔥**全国算电协同标杆**——国内首次数据中心 VPP 现货交易 |
| 标杆案例 | 联通韶关+移动广州/湛江三大数据中心，通过粤能投平台参与现货电能量交易与结算 |
| 技术架构 | 源网荷储智慧联动平台 + 边缘调控终端系列 |
| 聚合规模 | 灵活负荷超 **500MW** |
| 功能 | 聚合接入/智慧监控/电力市场云化统一服务 |

### 三大技术底座

| 赛道 | 能力 | 商业化 |
|------|------|:--:|
| 🔥构网型储能 | **全球首例**—全运会取代柴油发电机；首创"市电+储能"供电模式 | 已在多个项目示范 |
| SiC 电力电子 | 牵头**国家重点研发计划**，功率器件→装置全链条 | 多省规模化落地 |
| SST 研发 | 联合国家新型储能创新中心，打造高密度算力配电新范式 | 🔜 研发中 |

> 📌 南网科技的差异化：不依赖单一VPP平台收费，而是**储能+电力电子+SST全链条卖设备+方案**，VPP是拉动设备销售的入口。
