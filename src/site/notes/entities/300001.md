### 🔥算电岛（2026年6月6日发布 — 全球首创）

> 算力中心高压交直流预制舱供电站。将一整座 220kV 变电站装进预制舱，从"盖变电站"→"装预制舱"。

#### 产品定义

| 维度 | 说明 |
|------|------|
| 全称 | 算力中心高压交直流预制舱供电站 |
| 定位 | 全球首创，AI 算力中心的**预制能源底座** |
| 架构 | **高压直入（110/220kV）→ 中压直转 → 800V 直流直供** |
| 模块 | 167 个高压/中压/SST/直流配电/二次保护功能模块 |
| 核心器件 | 🔥自研 **SST 固态变压器**（SiC 高频拓扑，单台 2.5MW，效率 98.5%） |
| 供应链 | 时代电气提供 SiC 功率模块 |

#### 六大核心优势

| 优势 | 数据 | 说明 |
|------|:--:|------|
| **快** | 150 天交付 | 传统 12-18 月→5 个月，土建-70%、安装-80% |
| **新** | SST 架构 | 从充电 HVDC→算力 HVDC→SST 升级，2027 年挂网示范 |
| **智** | AI 调度平台 | 毫秒级感知电网/风光/算力负荷，动态调配；数字孪生+五级智能调控 |
| **绿** | 绿电利用率 **85-90%** | 风光直入 800V 直流母线，100% 就地消纳 |
| **省** | 综合成本大降 | Token 用电-30%、建站-20%、运维人力-40%、铜材-50%、混凝土-80% |
| **稳** | 可靠性 **99.9998%** | 六层 TPS 防护+N+1/2N 冗余，九级抗震，适配全国算力枢纽 |

#### 技术架构细节

```
220kV 市电 → 高压 GIS 配电 → 主变压器 → 10kV 中压配电
    → SST 固态变压器(10kV/800V DC) → 800V 直流母线 → 直供液冷算力机柜
    → 同时接入 风电/光伏 + 直挂式储能 + 动态构网
```

> 传统方案 4 级 AC-DC-AC-DC 转换 → 算电岛 **1 步到位**（AC-800V DC），全链路效率 **98.5%**。适配当前 60-100kW 液冷机柜 + 未来 **MW 级**超高密 AI 集群。

#### 算电协同 AI 智能体

> 依托特来电 VPP 平台 7,700+ 座电站、95 万充电桩、5,680 万用户的调度经验，将有序充电、负荷预测、储能移峰技术跨界复用至算力场景。平台可毫秒级感知电网波动、风光出力、算力任务负荷，动态调节算力策略：绿电富余时扩容算力任务，电网高峰时联动储能错峰 → **电力保证算力、算力协同电力**。

#### 行业意义

> 算电岛不是又一个变电站产品，而是**重构了数据中心供电的底层架构**。它解决了 AI 算力发展最痛的两个矛盾：①"算力等电"——服务器 6 个月到位、变电站要等 18 个月；②"绿电难消纳"——多级转换损耗大、新能源接入复杂。新华社、经济参考报、证券时报等权威媒体集中报道，定位为 **"下一代算力中心供电新范式"**。
