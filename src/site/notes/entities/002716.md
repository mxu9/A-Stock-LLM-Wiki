# 湖南白银（002716）

> 行业：有色/贵金属 | 定位：**国内唯一以白银为主业的A股上市公司**（原金贵银业，2024年重整），全球第三大白银冶炼企业，全产业链（探采选—多金属冶炼回收—精深加工）+湖南国资。8/24收11.46元（+9.98%，连续2日涨停），市值323.53亿。

## 🏢 主营业务

- **全产业链**：上游铅锌银矿采选 → 中游多金属冶炼综合回收 → 下游银基深加工
- 白银冶炼+白银制品销售+白银工业旅游；以银为核心，综合回收铅/锌/金/铋/锑/铜/铟/钯
- **品牌认证**："金贵"牌银锭 **LBMA+上期所双交割认证**；专利授权141件
- **冶炼产能2000吨/年**（全国前三，市场份额约10%）；**白银储量约573吨**（✅2026-08-28核实，首份报告"0.4万吨"系错误口径），自给率约30%（外购70%）
- 🆕**深加工新材料转型（报告3）**：光伏银浆产能500吨/年→**2026Q4扩至600吨/年**（跻身国内前五，客户隆基/通威/晶科，毛利率15-20%，预计新增营收12亿）；**高纯硝酸银扩至500吨/年**（2026Q3，进入**中芯国际/华虹半导体**供应链，毛利率20-25%，预计新增利润0.8亿）
- 🆕循环经济：郴州模式年处理"三废"200万+吨，近十年累计循环再生白银3.8万吨、黄金60吨；白银综合回收率99.5%，"三连炉-富氧熔池熔炼"自热熔炼技术
- **国资背景**：湖南省矿产资源集团14.91%+郴州国资6.44%，实控人湖南省国资委

## ⚔️ 竞争格局动态

- 与盛达（矿产）/兴业（资源储量）不同，湖南白银是**冶炼加工模式**：赚加工费+回收价差，毛利率仅6.63%（vs 盛达69%）
- 白银业务收入占比58.88%（报告3口径；报告1口径70.26%——前者为白银产品口径，后者含银基制品）
- ⚠️ 光伏银浆面临"少银化/无银化"技术路线风险：银浆占电池非硅成本62%，银价每涨1000元/KG→组件成本+0.9分/W；2026H1国内光伏新增装机仅72.07GW（**同比-66%**），行业开工率40-50%
- 无明确机构评级，中财网提示估值偏高（报告3口径PE 57.16x/8月）
