## 一、概念速览

**算力租赁 = GPU 租赁业务**：为客户提供高端 AI 芯片（H100/A100/H200/GB200 等）及算力集群服务，支持 AI 训练/推理，本质是"新型云厂商"。国内以"三二浮动制"合同为主（前3年价格固定、第4-5年浮动），另有按需付费模式；当前算力紧缺下年化定价 ≤3 年收回成本（三思行研 2026-04-15）。

### 2.2 核心驱动逻辑

**① 量变：Token 需求爆发**。AI 智能体/多模态应用落地 → 词元消耗指数级增长；国内 token 调用量连续 11 周全球第一（7月周调用 27.58 万亿）。2026Q1 算力租赁订单需求 = 2025 全年 2 倍+。

**② 质变：商业模式升级**。从"卖算力"到"卖 Token"——算力租赁公司手中的高端 NV 算力可产生优质 token，议价权显著提升，token 分成模式正在形成，估值将从 PE 切换到 PS（东吴）。

**③ 涨价周期确认**。H100 一年期租金 2025/10 的 1.7$/h → 2026/5 的 2.65$/h；GB200 时租 4.95$；阿里云 4/18 涨价最高 34%；DeepSeek 8/6 拟大幅上调 API 定价；下游大厂愿意为算力租金涨幅**兜底**（行云三签补充协议验证）→ 行业进入"加价潮"。

**④ 政策加持**。"十五五"算力网 4 万亿直投 + 政治局"人工智能+" + 北京 Token 经济政策 + 内蒙古 Token 交易平台。
