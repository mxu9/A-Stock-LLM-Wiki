# AIDC电源国产替代 可信度评估

> 评估对象：[[concepts/aidc-power\|aidc-power]] 中 20 只"国产替代"上榜标的（第一档 14 + 第二档 6）
> 数据截至：2026-08-16 | 验证手段：妙想 mx-search（20 只全量）+ mx-data（8 只抽查）交叉核验

## 1. 评估说明

### 1.1 方法
- **工作区证据**：aidc-power.md 国产替代章节 + 实体页/概念页
- **妙想验证**：mx-search 每只 1 次聚焦查询（认证/订单/市占/客户/澄清），弱证据标的加查；mx-data 抽查 8 只最新行情/财务
- **评级口径**：
  - 可信度 **S/A/B/C**：S=官方公告/招股书/公司披露；A=权威第三方/券商深度；B=研报/实体页转述缺一手；C=传闻/未证实或已澄清/证伪
  - 强度 **高/中/低**：稀缺性 + 产业进度 + 替代空间 + 客户绑定 四维综合
  - 验证结论：✅证实 / ◐部分证实 / ⚠️存疑 / ❌证伪

### 1.2 提示
- 评级基于公开信息与妙想检索交叉验证，不构成投资建议；个别结论以公司公告为准，搜索为二手资讯。

## 3. 逐股明细

### 3.1 ✅ 证实且强度高（第一梯队 7 只）

**1. 中恒电气 002364 — 可信度 S / 强度 高**
- 工作区：HVDC 国内 31% 市占第一（替代外资维谛 22%）、宁德 41 亿增资
- 妙想：✅ 8/14 公告实锤宁德 41 亿增资中恒科技 49% + 算力基础设施/充换电/新型电力系统三大领域战略合作；公司 240V/336V/800V 全系列；施耐德 CEO 访问（HVDC 互补合作信号）
- 风险：PE ~194x 高估值；HVDC 出海仍早期（东南亚/北美渗透率仅 1-5%）

**2. 中国西电 601179 — 可信度 S / 强度 高**
- 妙想：✅ 西电电力电子斩获海外数据中心 SST 订单 4 台 13.8kV（国产 SST 出海第一单）；主导制定数据中心 SST 行业标准；产品小批量商用、海外订单推进交付
- 风险：SST 收入占比小，特高压主业为主

**3. 四方股份 601126 — 可信度 S / 强度 高**
- 妙想：✅ 正式发布 SST1.0 并已量产（10kV→800V / 2.4MW / 98.5%）；35kV/13.8kV 计划 26Q3-Q4 发布；已与国内外主要客户合作
- 风险：维谛"排他合作"为星球传闻（低可信、无公告，妙想未证实）；SST 收入占比小

**4. 金盘科技 688676 — 可信度 A / 强度 高**
- 妙想：✅ 干变全球龙头（价值重估逻辑）；研报口径"SST 率先送样 & HVDC 量产订单"；聚焦数据中心扩展高压油变/GIS
- 风险：PE ~49x；海外产能爬坡

**5. 芯联集成 688469 — 可信度 S / 强度 高**
- 妙想：✅ 芯联动力 6/22 官宣 3300V SiC MOSFET；8/12 已向核心客户送样验证；高压 SiC 占 SST 整机价值量近 40%；BOM 降 20-35%；8 英寸 SiC 自研平台
- 风险：送样→量产周期；公司仍亏损

**6. 可立克 002782 — 可信度 S / 强度 中-高**
- 妙想：✅ 定增 3.89 亿"AI 算力电源核心磁性元件智造项目"（LLC&DAB 变压器/平面变压器/谐振电感）；国内磁性元件领先企业
- 风险："台达外购 50-60%"为研报口径；AI 收入占比待观察

**7. 中熔电气 301031 — 可信度 A / 强度 中-高**
- 妙想：✅ 获美国新势力车企 900VDC 电池包转换开关全球独家定点（约 2 亿元）；英伟达 800V HVDC Sidecar 供应链曝光入围的大陆厂商；2025 年报/26Q1 业绩高增长
- 风险：熔断器单柜价值量有限（数千元）；新能源车占比高受周期影响

- 结论：材料地位真，但 **SST 无订单** → "SST 高频变压器刚需受益"是概念推导，强度下调为低

**19. 科士达 002518 — 可信度 A / 强度 中-低**
- 妙想：◐ 公司 7/30 调研："现阶段重点推进兆瓦级 UPS、800V HVDC、巴拿马电源及 SST 等核心新产品研发与测试认证"，"尚处于验证导入"
- 结论：UPS 第二（已兑现），但 800V HVDC/SST **尚在研发验证**，"Q2-Q3 推出"是计划；台达 ODM 传闻未获证实

**20. 麦捷科技 300319 — 可信度 C / 强度 中**
- 妙想：⚠️ **核心 claim 存疑**——公司互动平台"**暂未正式取得 AVL 资质**"；媒体《英伟达 AVL 资质落空？麦捷科技"唯一供方"标签被撕》；但"麦捷科技与英伟达合作获进展"+TLVR 在 GPU 垂直供电不可替代（技术地位真实）；2025 营收 37.94 亿
- 结论：工作区"2026.5 官宣直供英伟达/首个进 GPU BOM"表述与公司"暂未取得 AVL 资质"矛盾 → **可信度降至 C，claim 需标注"待公司公告确认"**

## 4. 核心发现

### 🟢 被妙想升级/强化的 claim（7 条）
中恒电气宁德增资（公告实锤）、中国西电 SST 出海订单+行业标准、四方 SST 量产、芯联 3300V 送样、可立克定增扩产、中熔独家定点+Sidecar 链、新风光 SST 下线

### 🟡 被降级/需标注的 claim（9 条）
- 麦格米特"大陆唯一 NV 认证"（自述口径，A 非 S）
- 良信"双认证"（研报口径）
- 欧陆通"800V IBC 第二家"（IBC 证据不足）
- 科威尔"国产替代"（收入占比小）
- 京泉华"伊顿独家 MFT"（纪要口径，MFT 小试）
- 露笑 12 英寸（验证中）
- 横店东磁 AI 磁芯（材料环节，占比小）
- 科士达 800V HVDC（研发验证阶段）
- 泰永 SSCB（示范落地但未贡献业绩）

### 🔴 被证伪/存疑的 claim（3 条）
- **麦捷科技"直供英伟达/首个进 GPU BOM"**（公司：暂未取得 AVL 资质）⚠️ 最需警惕
- **安泰科技"SST 高频变压器刚需受益"**（公司：SST 无订单，配套研发阶段）
- **四方股份-维谛"排他合作"**（星球传闻，无公告，未获妙想证实）

## 5. 结论与配置含义

> 🔥 **真替代 vs 蹭概念的区分**：国产替代属性最扎实的是"**已有公告/量产/订单实锤**"的 7 只——中恒电气、中国西电、四方股份、芯联集成、金盘科技、可立克、中熔电气。
>
> 🟡 **"真逻辑但尚在早期"**：麦格米特（全栈真、估值极高）、良信（双认证未放量）、欧陆通（PSU 三强、IBC 待证）、科威尔（卡位真、收入小）、京泉华（MFT 小试）。
>
> ⚠️ **需警惕的 claim**：麦捷科技 AVL 资质（工作区表述需修正）、安泰科技 SST 无订单、泰永业绩变脸、科士达/科华 HVDC 未量产。
>
> 📌 **操作含义**：优先关注"妙想已证实+强度高"的 7 只；对"存疑 3 条"应在对应工作区页面加注 ⚠️，避免误当强逻辑使用。
