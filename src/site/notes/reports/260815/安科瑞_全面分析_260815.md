```
  配电监测      母线监测          全链路监测
  （每代架构都需要「卖水人」——安科瑞核心卡位）
```

**① 小母线监测（数据中心末端配电）**：
- 单柜价值量 3.2 万元，母线监测从选配→标配
- **58 个标杆项目落地**：中国移动广东东莞数据中心（15.1 万㎡/1.7 万机柜全覆盖）、秦淮数据环首都太行山基地（年均 PUE 1.16）、深圳华为、南通携程、山西联通、上海移动、无锡海力士
- 三种测温方案：AMB300 红外测温（测铜排）/ NTC 连接器（成本敏感）/ AMB400 分布式光纤（±0.15℃ 高精度）

**② SST 全链路监测（8/14 新发布）**：
- 覆盖 SST 从 10kV 中压并网→功率模块→高压直流输出全链路
- 弧光速断 ARB6-A6 + 无线测温 ATE400 + 直流绝缘 AIM-D100-TS + 局放 APD300-L + 直流计量 DJSF1352 + Acrel-EMS
- 解决传统保护/测温/互感器在 SST 高频 SiC 工况下易受干扰、误报、耐压不足的痛点
- 场景：AIDC 算力中心 800V 直流供电、储能 BESS、光伏汇集、直流微网、高速超充站

**③ 算电协同「卖水人」**（国盛证券 3/29 定位）：
- 以电优算：绿电直连（84 个项目已批/32GW）→ 源网荷储协同调度依赖用户侧微电网 EMS
- 以算调电：AIDC 枢纽节点 PUE≤1.2 硬约束 → 能效管理安装必要性提升
