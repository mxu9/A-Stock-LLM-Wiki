# 算力租赁 3-6个月投资筛选

> 筛选目标：找出 3-6 个月内可以参与的 A 股算力租赁标的。
> 风格不是行业弹性排名，而是「业绩已兑现 + 硬伤可控」的可投性筛选。

## 一、已确认的投资约束

| 决策项 | 约束 |
|------|------|
| 持有窗口 | 3-6 个月 |
| 范围 | 核心 6 只为主，第二梯队只做筛选 |
| 业绩闸门 | 2026H1 净利润已披露或预告，且同比高增长；只有订单、规划或收入高增不算兑现 |
| 杠杆闸门 | 核心候选资产负债率不高于 80%；高于 80% 必须同时满足 H1 兑现、经营现金流为正、长单可验证 |
| 质押闸门 | 高于 50% 直接排除；高于 30% 降权或观察 |
| 估值闸门 | 亏损、利润极小、千倍级 PE 或估值失真者只观察 |
| 仓位纪律 | 单票不超过 10%，主题合计 25%-30%；回撤 15%-20% 或买入逻辑破坏即复核 |
| 建仓方式 | 分三层：可分批、等验证/等回调、不参与 |

### 1. 智微智能：当前唯一可分批参与

**结论：可分批，不追高；建议先建观察仓或分 2-3 批。**

通过点在于：H1 为已披露的半年度报告（未经审计），收入 30.50亿元(+56.64%)、归母 3.88亿元(+281.92%)、扣非 3.72亿元(+324.60%)；智算业务收入 10.30亿元(+245.51%)，且毛利率约 83.7%。最新资产负债率 72.7%，低于 80% 硬闸；H1前十大股东质押数量均为0。以 H1 简单年化利润计算的市值/利润约 37x，低于表观 PE(TTM) 的失真程度。公司8月公告的担保授权总额较大，但实际对外担保余额1.204亿元、占2025年净资产5.34%，且无合并报表外担保和逾期担保。

风险不在报表杠杆，而在扩张与摊薄：公司拟募 28.7亿元建设智算中心、采购不超过 40亿元服务器，并参股 LPU 相关布局。若定增、采购或 Token 工厂商业化不及预期，估值会先于基本面回落。

**触发复核：** 回撤 15%；定增价格与摊薄落地；智算收入增速降至 100% 以下；毛利率跌破 70%；跌破 78-80元区间时重新评估逻辑。

### 2. 协创数据：业绩最强，但高杠杆豁免条件未齐

**结论：不急着追，等正式中报验证现金流和担保。**

协创的 H1 快报是核心六只中最强的：收入 126.41亿元(+155.69%)、归母 18.63亿元(+331.11%)、扣非 18.61亿元(+343.42%)，Q2 归母约 11.12亿元，环比 +48%。但 2026Q1 资产负债率 85.89%，有息负债和大规模采购已经显著抬升；公司 2026 年度合计申请授信不超过 500亿元、新增担保授权不超过 300亿元。按既定规则，高杠杆必须同时看到 H1 经营现金流为正和长单细节，快报本身不足以豁免。

**升级条件：** 正式中报经营现金流为正；资产负债率不再继续显著抬升；担保、融资租赁和客户回款结构可验证；估值回到 H1 年化利润 30x 附近或出现明确长单催化。

### 3. 利通电子：兑现强、弹性高，但不是现在的买点

**结论：等回调或 8月29日左右正式中报落地后再评估。**

H1 预告归母 6.5-7.5亿元、扣非 5.55-6.68亿元，同比增长极高，资产负债率 75.1%、质押 8.02%，风险闸门本身可控。问题是价格已经反映较多：最新市值 523.8亿元、PE(TTM) 98x，按扣非预告简单年化为约 39-47x，且业绩预告中包含股权投资公允价值变动和处置收益，利润质量要等正式中报拆分。

**参与条件：** 正式中报确认扣非质量；客户集中和大额订单续签可验证；股价回到对应扣非年化 35x 以下，或放量缩量结构明显消化。

### 4. 润泽科技：质量最好，但卡在业绩验证时点

**结论：中报前观察，披露后最可能升格为核心候选。**

润泽的最新优势是财务结构和业务壁垒：资产负债率 64.97%、质押仅 3.7%，PE(TTM) 22.9x 虽受 2025 年一次性收益影响，但扣非估值仍相对可接受。2026Q1 收入 18.40亿元(+53.55%)、归母 5.82亿元(+35.35%)，AIDC 业务处于上升期。

按用户确认的严格规则，H1 利润未披露就不能进「可分批」层。若中报确认扣非增长、经营现金流与上架率继续改善，它可能从观察层直接升到第一候选。

### 5. 宏景科技与东阳光：暂不参与

宏景的算力纯度高，但 2026Q1 资产负债率 89.82%，PE(TTM) 1395x，H1 利润尚未披露；即使算力订单弹性大，也已经同时触发杠杆和估值两道闸门。

东阳光 H1 已披露：收入 93.76亿元(+31.61%)，但归母 3.89亿元(-36.46%)、扣非 3.66亿元(-23.98%)。剔除股权激励和公允价值变动后的调整利润改善，仍不足以抵消质押 41.97% 和 PE(TTM) 2170x 的估值失真。等待秦淮数据相关业务单独验证，当前不进核心池。

## 四、执行清单

### 当前可做

1. **智微智能**：唯一进入可分批层。单票仓位不超过 10%，建议首批不超过 3%-4%，只在回撤或横盘缩量时加第二批。
2. **润泽科技**：加入中报观察池，不因板块热度提前放宽业绩闸门。
3. **协创数据、利通电子**：分别盯正式中报现金流/担保、扣非质量与客户集中，等待验证或回调。

### 暂不做

1. 宏景科技：杠杆、估值、业绩验证三缺二。
2. 东阳光：表观利润下滑、质押降权、估值失真。
3. 第二梯队：等正式利润基数出现，不因题材联动参与。

### 3-6个月催化剂

- 8月下旬中报：润泽、宏景、协创正式报告，利通预约 8月29日左右。
- 9-10月三季报：验证算力租赁是否从 H1 脉冲变成连续利润。
- DeepSeek/阿里云涨价落地、字节招标结果、北京 Token 经济政策。
- 英伟达新云模式和海外 neocloud 资本开支对国内订单预期的传导。

### 卖出/复核信号

- 个股回撤 15%-20%，或算力租赁主题合计仓位超过 30%。
- 智微定增摊薄超预期、智算毛利率显著下行。
- 协创现金流、担保或负债率继续恶化。
- 利通客户集中、非经常性收益占比过高。
- 润泽中报扣非或经营现金流低于预期。
- 行业层面出现 GPU 供给快速宽松、租金价格战、Token 调用量增速放缓。

## 五、结论

在「3-6个月、业绩已兑现、硬伤可控」的口径下，**当前唯一值得分批参与的是智微智能**。协创数据是业绩弹性最强的候选，但高杠杆豁免条件尚未齐备；利通电子要等估值和正式中报；润泽科技是最可能在中报后升格的优质候选；宏景科技和东阳光暂不参与。

这个排序与 8/14 行业弹性排序不同，原因是本次加入了用户确认的硬性风险闸门：宁可少赚赛道泡沫，也不把「高景气」当成放宽杠杆、估值和业绩验证的理由。
