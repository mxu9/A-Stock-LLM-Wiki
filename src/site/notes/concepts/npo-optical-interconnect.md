# 🔬 NPO 近封装光学

> 🔥 2026-08-05 东北证券深度报告《NPO：国产算力的新战场，AI 光互联的新主线》 | 国内头部 CSP 完成全系统验证，NPO 从实验室走向规模化工程落地

## 概念定位

NPO（Near Package Optics，近封装光学）是**传统可插拔光模块与 CPO（共封装光学）之间的实用过渡方案**：将光引擎与交换芯片（ASIC）近距集成部署，缩短电气走线、降低信号损耗与功耗，同时保留独立封装与可维护性，破解下一代 AI 集群与超大规模数据中心的性能瓶颈。

- **与 CPO 关系**：NPO 安装在电路板上、CPO 集成在芯片封装内部；两者底层光子芯片与制造工艺强共通（GFS SCALE 平台可同时覆盖两种路线）
- **量产节奏**（招商电子 GFS 26Q2 跟踪）：NPO 预计 **2027 年开始爬坡**，CPO 2028 年开始爬坡；NPO 系统变化较小、可延续部分 SiGe 和现有光模块技术，客户导入更快
- **价值量**（星球 08-15 信号）：NPO 提升 12 寸硅光价值量约 **4 倍**，TIA/Driver 价值量增加 **3 倍**
- **标准推进**：国内云厂商、设备商、芯片厂与光通信企业共同参与 OPENNPO 等标准制定，中国产业链有望从参与者转向共同定义者

## 传导链

```
AI 集群/超节点 → 高速互连升级（可插拔 → NPO/CPO）
  ├─ 光引擎：模块厂向近封装方案延伸（中际旭创/新易盛/光迅/华工）
  ├─ 高密度光连接：MT 插芯/高密度连接器（太辰光/长芯博创/仕佳/致尚）
  ├─ FAU/半导体光学：耦合精度与通道密度（天孚/光库/杰普特/炬光）
  ├─ 光源及上游材料：高功率 CW/VCSEL、InP 衬底（源杰/东山精密/长光华芯/云南锗业）
  └─ 先进封装：PIC/EIC 异构集成（长电科技）
```

## 🏆 核心标的（东北证券 08-05 深度报告）

| 环节 | 标的 | 逻辑 |
|------|------|------|
| 光引擎 | 中际旭创、新易盛、光迅科技、华工科技 | 模块厂向近封装方案延伸，系统级交付能力强化壁垒；新易盛 6.4T NPO 产品化展示、光迅 3.2T NPO 率先通过国内 CSP 验证 |
| 高密度光连接 | 太辰光、长芯博创、仕佳光子、致尚科技 | 高密度连接产品供应商高度受益；致尚深度绑定 SENKO |
| FAU/半导体光学 | 天孚通信、光库科技、杰普特、炬光科技 | 高通道 FAU 与光引擎配套；杰普特 FAU 已成 Coherent CPO 供应商 |
| 光源及上游材料 | 源杰科技、东山精密、长光华芯、云南锗业 | CW 光源加速放量；磷化铟产能扩张 |
| 先进封装 | 长电科技 | XDFOI 向硅光封装延伸，光电融合平台 |
| 国产算力/交换芯片 | 摩尔线程、沐曦股份、盛科通信、中兴通讯 | 超节点自主化提速，主芯片放量牵引光互连需求 |
