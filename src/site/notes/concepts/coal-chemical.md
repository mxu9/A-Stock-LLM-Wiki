# 🏭 煤化工

## 🔗 产业链

```
煤炭开采 → 煤气化 → 合成气(CO+H2) → 甲醇/合成氨
                                         ├── 烯烃(CTO) → PE/PP/EVA
                                         ├── 醋酸/DMF/DMC/己内酰胺
                                         ├── 尿素(化肥)
                                         └── 煤制油/煤制气
```

## 🔑 核心投资逻辑

1. **煤油比套利**：Brent $96 vs 秦港775元→煤头烯烃利差突破1000元/吨，煤化工成本优势历史性放大
2. **产能释放**：宝丰520万吨烯烃满产+宁东四期50万吨年底投产；华鲁荆州基地放量+气化平台技改
3. **新材料升级**：EVA/POE/DMC/EMC/BDO/NMP/TDI高附加值转型打开第二曲线
4. **业绩兑现**：宝丰H1近百亿创纪录，华鲁Q1+58%且Q2价差继续走扩，广信农药景气触底回升
5. **分红催化**：华鲁拟中期分红≥30%净利，宝丰高现金流支撑高分红

## ⚠️ 风险

- 油价回落→煤化工成本优势收窄（但当前中东冲突短期难解）
- 6000亿新投资→3年内供给冲击（聚烯烃2026有望触底反弹）
- 碳减排双控政策压制长期估值
- 宝丰市值蒸发千亿：利润新高但股价跌43%，市场担忧周期持续性

## 📅 催化剂
