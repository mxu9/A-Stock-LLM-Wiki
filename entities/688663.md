## 主营业务

大功率电力电子节能控制技术为核心，五大业务板块（2025 营收占比，方正证券口径）：**高中低压变频器 47% + 高压动态无功补偿装置（SVG）27% + 智慧储能系统 11% + 智慧矿山装备 6% + 轨交再生制动能量吸收装置 4%**。前身 1970 年国营汶上无线电厂，2004 年改制成立，2021-04 科创板上市，实控人山东省国资委（山东能源集团持股 38.25%）。

## 🔥 SST / AIDC 布局（核心看涨期权）

- **SST 下线（2026-03-25）**：新一代固态变压器正式下线，10kV 输入 / 800V 直流输出 / 2500kW，双向 H 桥级联 + SiC 宽禁带器件；占地缩减 50%、转换效率 98.5%、供电效率 +2-4%、PUE 可降至 1.15 以下；电压覆盖至 13.8kV，输入侧构网、单元冗余；「硅+SiC」混合方案过渡，后续全 SiC（华鑫 7/20）
- **AIDC 解决方案（2026-06-17 发布）**：「SST+构网储能」构网型智慧能源路由器，供电链路简化、系统效率 +3-5%、构网储能提供惯量支撑——与 800V HVDC 高压直流化（中信证券 8/11 定性为 AIDC 供电终局方案）路线高度契合
- **SST 进展**：样机迭代/示范验证阶段，暂无收入贡献；已与多家境内外客户初步洽谈；针对海外算力中心/智能微网/新能源车超充二次开发；海外认证有序推进（互动平台 7/3-7/10）
- **远山新材料合作框架**：1200V-3000V 蓝宝石基底高压 GaN 器件量产后优先采购，保障 SST 核心功率器件（方正 8/12）
- **数据中心存量**：SVG 用于乌兰察布零碳智算基地（16 台）、阿里张北/华海云谷/绿巨人张北/三大运营商数据中心，累计 70 台设备服务数据中心；高压变频器用于数据中心冷水机组压缩机驱动（4/23 业绩说明会）
- **华为合作（2025-08 战略协议）**：构网型储能、微电网、数据中心供配电系统深度协同；储能技术共识为组串式+高压级联（未来主流）+「储能+SSC」组合（超发 15% 仍稳定支撑电网）

## SVG / 电能质量

- 网外市场市占率 **~25%**，2024 年获评「国家制造业单项冠军」（IR 2/4）；行业标准深度参与者
- 产品：0.4kV-35kV 全系列（户外/户内、风冷/水冷）；2026 研发 35kV 直挂 SVG 专机、66kV 直挂系列化
- 代表案例：中广核三澳核电（3/6 投运，功率因数 0.98+）、山东能源东营渤中海上风电、华润广东风电场 SVG 升级改造
- 2026 年国内 SVG 市场预计突破 68.5 亿元（2025 年报口径）

## 储能 / 其他新兴方向

- **高压级联储能国内领先**：无变压器直挂 6-35kV、一级能量转换、模块化冗余；东营 2×200MWh 一期投运国内首套单机容量最大百兆瓦级高压级联储能；靖远 150MW/600MWh 独立共享储能提供全套高压级联设备；鲁西电厂火储联合调频（磷酸铁锂+超级电容）
- 产品推进：1000V-500kW PCS 研发、3.5MW PCS 推进；SSC 功率扩展至 50MVA+（毛利率高于 SVG，试点验证阶段）
- **绿电制氢电源**：2026 年计划立项研发（山能煤化工绿氢需求）；**核聚变电源**技术研究（EAST 装置已有应用）；变频器新品：6kV/10kV 1600kW 防爆四象限、1140V 400kW SiC 四象限轴向磁通一体机
