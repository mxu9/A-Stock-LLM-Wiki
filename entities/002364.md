## 🔥 产品矩阵

### Panama 800V 预制化电力模组

| 指标 | 参数 |
|------|------|
| 架构 | 10kV中压直转240V/400V/**800V** 直流，4级链路→**1级** |
| 系统效率 | 97.5%+（DC-to-Chip 直供模式最高 **98.5%**） |
| 单套功率 | 支持 **2.5MW** IT负载（最高 **3.6MW** 高密度机柜） |
| 铜材节省 | 减少 **45%** 以上 |
| 交付方式 | 预制化部署、模块化扩容 |

### Super X 双方案

| 方案 | 定位 |
|------|------|
| **Super X Panama-800VDC** | 新建方案：10kV→800V直转，面向新数据中心 |
| **Super X Aurora-800VDC** | 改造方案：传统机房供电升级至800V DC |

### 完整产品线

```
HVDC(240V/336V/800V) + Panama(240V/400V/800V) + 中低压配电 + 精密配电 + 服务器PSU
                                              ↓
                              端到端电力解决方案，深度适配通用/AI/超算
```
