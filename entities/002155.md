### 产业链完整度

```
矿山勘探 → 开采 → 选矿 → 冶炼 → 精炼 → 深加工

黄金线：金矿 → 标准金锭（100吨/年精炼线）
锑品线：锑矿 → 精锑/氧化锑/乙二醇锑/阻燃母粒（2.5万吨冶炼+4万吨深加工线）
钨品线：钨矿 → 仲钨酸铵(APT)
```

> 📌 湖南黄金是国内**唯一同时拥有金锑钨完整采选冶+深加工产业链**的企业。
