# DrMOS / AI服务器供电功率级

> DrMOS（Driver-MOSFET智能功率级）= 驱动IC+高边/低边MOSFET单封装集成，AI服务器GPU/CPU核心供电（POL第三级电源）标配。**量价齐升 + 国产替代共振**：AI服务器单机用量320-400颗→640-720颗，前四大海外厂占85%，国产合计仅~7%，MPS/英飞凌对华为license到期+产能挤占打开替代窗口。

## 📐 技术与卡位

| 维度 | 要点 |
|------|------|
| 定义 | 驱动器IC+高边+低边MOSFET集成封装，12V→1V左右大电流POL供电 |
| 四大优势 | 转换效率90-95% / 板面积为分立方案1/4 / 动态响应快数倍 / 工作温度降10-15℃ |
| 技术壁垒 | BCD工艺（双极+CMOS+DMOS，良率爬坡6-12个月）+ 高热密度封装 + 系统协同（SVID/AVSBus协议、DPM动态相位管理）——"模拟芯片皇冠明珠" |
| 用量演进 | H100时代320-400颗/台 → Blackwell 640-720颗/台；电流50A→80/90A+；单颗$1.5→$2.5+；电源管理BOM $80→$1000+ |
| 架构演进 | 12V传统 → 48V垂直供电（VPD）→ 800V HVDC；TLVR/模块化POL中期导入；IVR/封装级供电远期 |

## 📊 市场规模与格局（多源交叉）

**格局（✅多源一致）**：MPS约50%（6/9产业文+8/10英飞凌报道"约五成"）+ 英飞凌约25%（服务器领域60%口径为细分领域，见⚠️）+ 瑞萨/TI跟随——**前四大合计约85%**（国金8/25、长见观察6/7、DrMOS全景6/9三源一致）；国产合计仅约7%。

**规模测算（口径分歧大，⚠️引用需标注来源）**：

| 口径 | 数据 | 来源 |
|------|------|------|
| 全球市场 | 2024年23亿美元；2025年AI增量即达18亿 | VPD跟踪6/15（产业文） |
| 长期空间 | 2028年6000万颗算力芯片×100颗/颗×$2 → **120亿美元** | 晟盟资产7/7 |
| PDF口径 | 2025年23亿→2027年37.3亿美元（CAGR 9.96%） | ⚠️PDF内部矛盾：23→37.3两年CAGR应为27%而非9.96%，**数字有误** |

**供需**：8英寸成熟制程产能2025年下滑、2027年进一步收缩；MPS/英飞凌在手订单高增、渠道库存紧张、4月已涨价7月再涨（VPD跟踪6/15）；英飞凌与多家AI客户签多年期产能预留协议（累计高个位数十亿欧元+预付款，8/10报道）。

## 🔥 国产替代窗口（核心逻辑）

1. **license到期**：MPS、英飞凌对华为的供应商license均已到期，海外厂新增产能优先投向海外盈利市场，续约概率低（VPD跟踪6/15、晟盟7/7）
2. **产能挤占**：台积电8英寸BCD产能转向CoWoS先进封装（PDF口径，产业逻辑自洽）
3. **国产化要求**：国产AI芯片链要求高国产化率——华为昇腾链95%国产化率（PDF口径，方向与产业文一致）
4. **认证窗口**：海外大厂向电源模组延伸与台达竞争 → 台达有意愿导入国产供应商
