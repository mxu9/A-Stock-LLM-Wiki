# 💰 红利ETF

> 低利率时代防御配置核心工具 | 10年国债1.75% vs 中证红利股息率4.33%（利差2.58pct，近13年80%分位）| Q2以来吸金超350亿 | 华泰柏瑞红利全家桶总规模639亿

## 📊 市场背景

| 指标 | 数据 | 说明 |
|------|------|------|
| 10年期国债收益率 | **1.745%** | 低利率环境持续 |
| 中证红利指数股息率 | **4.325%** | 利差超2.5pct，历史高位 |
| 红利ETF Q2净流入 | **超350亿元** | 资金持续涌入 |
| 红利ETF月内涨幅 | **最高+17%** | 防御+估值修复双驱动 |
| 全市场红利ETF总规模 | **约2500亿+** | 华泰柏瑞一家占1/4（639亿） |

> 📌 核心逻辑：低利率→红利资产股息回报 vs 无风险利率溢价达历史极值。叠加央企市值管理+分红季，红利类ETF成资金避风港。

## ⚠️ 注意事项

| 风险/注意 | 说明 |
|------|------|
| 股息率陷阱 | 高股息≠好公司，需结合ROE/现金流质量筛选 |
| A/H红利税差异 | A股持股>1年免税，港股通红利税20%（QDII可优化） |
| 行业集中度 | 银行/煤炭/石油石化占比较高，周期属性明显 |
| 规模分化 | 头部产品集中度高，尾部流动性不足 |
| 费率差异 | 0.15%-0.50%不等，长期持有应选低费率 |
